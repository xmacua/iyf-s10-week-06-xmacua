## Project Description
A responsive weather dashboard built with HTML, CSS, and JavaScript using the OpenWeatherMap API. The app fetches live weather data for cities entered by the user and displays current conditions with a clean interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- LocalStorage

## Features
- Search weather by city name
- Display current temperature, weather description, feels-like temperature, humidity, wind speed, and pressure
- Show weather icon provided by OpenWeatherMap
- Loading indicator while data is fetched
- Error handling for invalid city names and API/network issues
- Recent search history stored in localStorage
- Clickable recent searches for fast lookup

## How to Run
1. Open `index.html` in your browser.
2. Open `app.js` and replace `your_api_key_here` with your OpenWeatherMap API key.
3. Search for a city name and view the current weather data.

## Lessons Learned
I learned how to build a weather app by integrating a third-party API and handling async requests with `fetch` and `async/await`. I also practiced updating the DOM dynamically and storing persistent data in `localStorage`.

## Challenges Faced
Managing API error responses and keeping the UI responsive were the biggest challenges. I resolved these by adding explicit error handling, a loading state, and a clean fallback for empty search history.
